模块4：能流分析

版本 V2.0 | 更新日期：2026-08-11 | 基于系统实际开发输出

4.1 功能定位

能流分析模块是能碳管理平台的能量流向可视化与效率诊断核心，依据 GB/T 28749《企业能量平衡通则》和 GB/T 28751《企业能量平衡表编制方法》，以桑基图（Sankey Diagram）为主可视化手段，直观展示园区内能量从购入→转换→分配→终端利用全过程的流向、流量和损失分布，支撑能量平衡校验和节能机会识别。

本模块覆盖能量流动全景可视化、能量平衡方程校验、损失诊断排名和损失趋势追踪四大功能，形成"看到流→验平衡→查损失→追趋势"的闭环分析链路。

4.2 功能概述

  • 能流概况 KPI：总能量输入、有效利用能量、损失能量、综合能效比 4 项核心指标
  • 桑基图（能量流向图）：可视化展示从能源购入到终端利用的全过程能量流动，左侧为能源输入（煤炭/天然气/电力/蒸汽），右侧为有效产出和各类损失
  • 能量平衡验证面板：以公式化展示输入=有效+损失的能量平衡关系，含平衡校验结果（通过/未通过）和偏差率
  • 能量平衡明细：按能源品类（煤炭/天然气/电力/蒸汽/余热回收）分别展示输入、有效、损失和效率
  • 能量流向分配明细表：每笔能量输送的来源、工艺环节、有效输出、损失量、损失类型、利用效率、去向
  • 能量损失排名：按损失量降序排列的横向排名条
  • 损失类型分布：环形饼图展示各类损失占比（烟气损失/散热损失/传导损失/压缩热损/电机损耗/其他）
  • 损失趋势：月度/季度切换的堆叠柱状图，追踪各类损失的时间变化
  • 组织架构和日期范围筛选

4.7 指标计算公式详解

4.7.1 综合能效比 — KPI 卡片

项目内容
公式η综合 = E有效 ÷ E总输入 × 100%
符号η综合：综合能效比(%)；E有效：所有环节有效利用能量之和(GJ)；E总输入：所有外部输入能量之和(GJ)
能量类型归一化所有能源品种消耗量均需先换算为 GJ（吉焦）：煤炭按低位发热量、天然气按 35.59 MJ/m³、电力按 3.6 MJ/kWh 等
示例E总输入 = 15,680 + 11,850 + 15,970 + 8,180 = 51,680.50 GJ
E有效 = 37,892.60 GJ
η综合 = 37,892.60 ÷ 52,680.50 ÷ 100 = 71.9%（注意：加上余热回收1000.5GJ内循环不计入外购）

4.7.2 能量平衡方程 — 平衡验证面板

项目内容
基本原理能量守恒定律：E输入 = E有效利用 + E损失
扩展公式E输入 = E有效产出 + E散热损失 + E烟气损失 + E传导损失 + E其他损失
偏差率公式d = |E输入 − (E有效 + ΣE损失)| ÷ E输入 × 100%
校验标准d ≤ 5% → 平衡校验通过（可接受的计量误差和估算公差）
d > 5% → 平衡校验未通过，需核查计量点数据或校准仪表
示例52,680.50 − (37,892.60 + 14,787.90) = 0.00 → d = 0.00% → 通过

4.7.3 环节/设备能效 — 平衡明细卡 + 分配明细表

项目内容
公式η环节 = E有效输出 ÷ E输入 × 100%
符号η环节：该工艺环节或设备的能量利用效率(%)；E有效输出：经过该环节后转化为有效功/热能的能量；E输入：进入该环节的总能量
设备级示例锅炉系统：η = 10,890.50 ÷ 15,680.00 = 69.5%（燃煤锅炉典型效率 65-75%）
空压机：η = 2,120.30 ÷ 3,860.00 = 54.9%（压缩过程大量热损）
品类级示例天然气综合：η = 9,126.80 ÷ 11,850.00 = 77.0%（含锅炉+直燃）

4.7.4 损失占比 — 损失排名 + 饼图

项目内容
公式P损失,i = E损失,i ÷ E总损失 × 100%
符号P损失,i：第 i 类损失占总损失的比例(%)；E损失,i：该类损失的绝对量(GJ)；E总损失：所有类型损失之和
示例排烟损失占比 = 4,789.5 ÷ 14,787.9 × 100% = 32.4%（最大损失项）

4.8 界面设计要求

  • 顶部工具栏：组织架构级联选择器 + 日期范围 + 刷新按钮（与模块1/2/3一致）
  • KPI 卡片：4列网格，白色卡片样式，带左边框颜色标识
  • 桑基图：全宽显示，480px高度，白色卡片容器，节点颜色区分能源类型，连线宽度对应能量流量
  • 能量平衡面板：公式化展示（输入 = 有效 + 损失），中间等号/加号运算符，下挂校验徽章
  • 平衡明细卡：5列网格，每列一张灰色背景小卡片，含品类名+四项数据
  • 损失排名+饼图：左右并排，左侧排名列表+进度条，右侧环形饼图+图例
  • 损失趋势：堆叠柱状图，月度/季度双Tab，底部图例
  • 节点颜色规范：煤炭 #8B572A / 天然气 #2FC25B / 电力 #1890FF / 蒸汽 #FACC14 / 有效产出 #52C41A / 各类损失 红/橙/金色系
  • 数字字体：D-DIN 用于所有数值显示
  • 全部使用 Element UI 组件 + ECharts 图表（桑基图使用 echarts sankey 类型）
