模块2：能源消费量和强度计算

版本 V2.0 | 更新日期：2026-08-04 | 基于系统实际开发输出

2.1 功能定位

能源消费量和强度计算模块是能碳管理平台的核心统计模块，负责将各用能单元采集的原始能源数据按 GB/T 2589《综合能耗计算通则》折算为标准煤（tce），并在此基础上计算单位产值能耗、单位增加值能耗、单位产品能耗等强度指标，为能效对标和目标考核提供数据基础。

本模块拆分为两个独立子页面：能源消费量和能源强度，通过侧边栏二级菜单进入。

2.2 功能概述

2.2.1 能源消费量

  • 综合能耗计算：按6大能源品类（固体燃料/液体燃料/气体燃料/电力/热力/其他燃料）汇总实物消耗量，乘以折标系数，得出各品种折标煤量及占比
  • 品类统计看板：6张 KPI 卡片分别展示六大品类的 tce 值和环比趋势
  • 车间产值填报：各车间/产线的当期产值录入，用于计算单位产值能耗
  • 按车间/产线汇总的能源消费明细表，展示各车间六大品类消耗和合计
  • 自由日期范围选择，支持任意起止日期查询

2.2.2 能源强度

  • 强度指标计算：单位产值能耗、单位增加值能耗、单位产品能耗、节能量
  • 强度趋势图：按月展示单位产值能耗和单位增加值能耗的变化趋势
  • 产品产量填报：各产线的主要产品、产量录入，自动计算单位产品能耗
  • 能效排名：按车间/产线的能耗强度排名，含能效等级评定
  • 目标考核：年度强度目标、节能量目标、下降率目标、清洁能源占比目标的完成进度
  • 自由日期范围选择

2.6 指标计算公式详解

2.6.1 综合能耗（Etce）— 能源消费量页·工具栏右侧 + 折标煤表合计行

项目内容
公式Etce = Σi=1n (Ei × Ki)
符号说明Ei：第 i 种能源品种的实物消耗量（t / 万m³ / 万kWh 等）
Ki：第 i 种能源品种的折标准煤系数（kgce/单位），n=8（8种能源品种）
数据来源Ei 来自各计量点采集的实物消耗量；Ki 来自系统设置→折标系数管理（参照 GB/T 2589）
计算示例原煤消耗 1,256.80 t × 0.7143 = 897.92 tce；天然气 45.80 万m³ × 12.143 = 556.15 tce
综合能耗 = 897.92 + 108.00 + 32.78 + 12.07 + 556.15 + 289.68 + 77.04 + 9.26 = 1,906.78 tce
显示位置能源消费量页·工具栏右侧（蓝色大字）+ 折标煤表合计行
更新频率每次查询/刷新时重新计算

2.6.2 六大品类 tce 值 — 能源消费量页·KPI 卡片行

品类公式示例
固体燃料E固体 = E原煤×K原煤 + E洗精煤×K洗精煤 + E焦炭×K焦炭 + E煤矸石×K煤矸石897.92 + 108.00 = 1,005.92 tce
液体燃料E液体 = E原油×K原油 + E汽油×K汽油 + E煤油×K煤油 + E柴油×K柴油 + E燃料油×K燃料油 + ELPG×KLPG32.78 + 12.07 = 44.85 tce
气体燃料E气体 = E天然气×K天然气 + E焦炉煤气×K焦炉煤气 + E高炉煤气×K高炉煤气 + ...556.15 tce
电力E电力 = Σ (E电力,j × K电力)，K电力=1.229 kgce/万kWh289.68 tce
热力E热力 = E蒸汽 × K蒸汽 + E热水 × K热水77.04 tce
其他燃料E其他 = E甲醇×K甲醇 + E乙醇×K乙醇 + E氢气×K氢气 + E生物质×K生物质9.26 tce

注意：品类 KPI 值为该品类下所有子品种折标煤之和。当品类下只有一个品种时直接使用该品种的 tce 值。KPI 卡片同步显示环比趋势（本期与上期对比的变化率）。

2.6.3 单个能源品种折标煤 — 综合能耗计算表

项目内容
公式tcei = Ei × Ki
符号tcei：第 i 个品种的折标煤量(tce)；Ei：实物消耗量；Ki：折标系数(kgce/单位)
示例原煤：1,256.80 t × 0.7143 = 897.92 tce；洗精煤：120.00 t × 0.9000 = 108.00 tce

2.6.4 各品种占比 — 综合能耗计算表·占比列

项目内容
公式Pi = (tcei ÷ Etce) × 100%
符号Pi：第 i 个品种占综合能耗的百分比；tcei：第 i 个品种的折标煤量；Etce：综合能耗合计
示例原煤占比 = 897.92 ÷ 1,906.78 × 100% = 47.1%；天然气占比 = 556.15 ÷ 1,906.78 × 100% = 29.2%
验证所有品种占比之和 = 100%

2.6.5 车间/产线综合能耗 — 能源消费明细表·合计列

项目内容
公式E车间 = E固体 + E液体 + E气体 + E电力 + E热力 + E其他
符号E车间：该车间/产线在所选时间段内的综合能耗(tce)，各项为六大品类在该车间的消费量
示例一车间A线合计 = 320.5 + 12.3 + 45.2 + 85.6 + 22.1 + 2.5 = 488.2 tce

2.6.6 环比变化率 — KPI 卡片趋势标签

项目内容
公式Δ = (E本期 - E上期) ÷ E上期 × 100%
符号E本期：所选时间段的品类 tce 值；E上期：上一相等长度时间段的品类 tce 值
趋势方向Δ > 0 → ↑ 增长（红色，能耗增加为不利）；Δ < 0 → ↓ 下降（绿色，能耗减少为有利）
示例固体燃料：本期 1,005.92，上期 978.52 → Δ = (1005.92-978.52)÷978.52 = 2.8% ↑

2.6.7 单位产值能耗 — 能源强度页·KPI + 强度指标面板

项目内容
公式e产值 = Etce ÷ V
符号e产值：单位产值能耗(tce/万元)；Etce：综合能耗(tce)；V：产值(万元，来自能源消费量页→产值填报表)
示例Etce = 1,906.78 tce，V = 5,017.89 万元 → e产值 = 1,906.78 ÷ 5,017.89 = 0.38 tce/万元
参考标准GB/T 32045《工业企业能源管理体系实施指南》

2.6.8 单位增加值能耗 — 能源强度页·KPI + 强度指标面板

项目内容
公式e增加 = Etce ÷ Vadd
符号e增加：单位增加值能耗(tce/万元)；Etce：综合能耗(tce)；Vadd：工业增加值(万元) = 产值 - 中间投入
示例Etce = 1,906.78 tce，Vadd = 3,668.81 万元 → e增加 = 0.52 tce/万元

2.6.9 单位产品能耗 — 能源强度页·产品产量填报表

项目内容
公式e产品 = Etce,产线 ÷ Q
符号e产品：该产线单位产品能耗(tce/单位产品)；Etce,产线：该产线的综合能耗(tce)；Q：产品产量(t/m²/台等)
示例A线(粗加工)：Etce=325.6，Q=1,250 t → e产品=0.260 tce/t
E线(总装)：Etce=127.5，Q=580 台 → e产品=0.220 tce/台
设计要点不同产线/产品使用不同的产量单位（t / m² / 台），系统自动识别并计算

2.6.10 节能量 — 能源强度页·KPI 卡片

项目内容
公式S = Etce,基期 - Etce,本期
符号S：节能量(tce)；Etce,基期：基期综合能耗（上一年同期）；Etce,本期：本期综合能耗
替代公式S = (e基期 - e本期) × V本期（基于强度变化计算）
示例基期 2,088.78 - 本期 1,906.78 = 182 tce 节能量；（另一种算法）：(0.42-0.38)×5,017.89 = 200.72 ≈ 201 tce。实际取值取节能措施累加值

2.6.11 能耗强度 — 能效排名表

项目内容
公式e车间 = E车间 ÷ V车间
符号e车间：该车间的能耗强度(tce/万元)；E车间：该车间的综合能耗(tce)；V车间：该车间的产值(万元)
示例一车间A线：1,825.60 ÷ 5,680.00 = 0.32 tce/万元 → 排名第1
锅炉房：558.58 ÷ 980.00 = 0.57 tce/万元 → 排名第8
能效等级判定e ≤ 0.35 → 1级（先进）；0.35 < e ≤ 0.50 → 2级（中等）；e > 0.50 → 3级（落后）。阈值可在系统设置→强度目标设置中配置

2.6.12 目标考核完成率 — 目标考核进度条

项目内容
公式R = Qactual ÷ Qtarget × 100%（目标值越低越好时，如能耗强度）
或 R = Qactual ÷ Qtarget × 100%（目标值越高越好时，如节能量）
符号R：完成率(%）；Qactual：实际值；Qtarget：目标值（来自系统设置→强度目标设置）
示例年度强度目标：0.40 tce/万元，实际 0.38 → 越低越好 → R = 0.40÷0.38 ≈ 105%（超额完成，显示 95% 保守值）
节能量目标：500 tce，实际 380 tce → R = 380÷500 = 76%
进度条颜色R ≥ 100% → 绿色(#52C41A)；80% ≤ R < 100% → 蓝色(#1890FF)；R < 80% → 橙色(#FAAD14)

2.6.13 化石能源占比 — 能源消费量页·KPI

项目内容
公式P化石 = (E固体 + E液体 + E气体) ÷ Etce × 100%
示例(1,005.92 + 44.85 + 556.15) ÷ 1,906.78 = 84.3%

2.6.14 清洁能源占比 — 能源消费量页·KPI

项目内容
公式P清洁 = (E电力(光伏/风电/水电) + E生物质) ÷ Etce × 100%
示例光伏发电对应电力约占 15.7%（含光伏自发自用部分）
验证化石占比 + 清洁占比 = 100%

2.7 界面设计要求

  • 顶部工具栏：组织架构级联选择器 + 日期范围 + 综合能耗合计（右侧）
  • KPI 卡片行：6列网格（能源消费量）/ 4列网格（能源强度）
  • 数据表格：白色卡片样式，圆角 8px，阴影
  • 数字字体：D-DIN（等宽数字）用于所有数值显示
  • 品类颜色：固体燃料 #4A4A4A / 液体燃料 #CD853F / 气体燃料 #2FC25B / 电力 #1890FF / 热力 #FACC14 / 其他燃料 #722ED1
  • 能效等级：1级绿色 / 2级橙色 / 3级红色
  • 全部使用 Element UI 组件 + ECharts 图表
