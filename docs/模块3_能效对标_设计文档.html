模块3：能效对标

版本 V2.0 | 更新日期：2026-08-11 | 基于系统实际开发输出

3.1 功能定位

能效对标模块是能碳管理平台的绩效评估核心，依据 GB/T 32045《工业企业能源管理体系实施指南》和 GB/T 36711《用能单位能效对标指南》，将企业各用能单元的能耗指标与国家/行业基准值进行对比分析，诊断能效差距，设定改进目标，为节能改造决策提供量化依据。

本模块覆盖三大对标维度：国标强制性限值对标、行业先进水平对标和内部车间/产线横向对标，形成"外部对比+内部排名"的双循环改进机制。

3.2 功能概述

  • 国标对标面板：展示 6 项关键能效指标与国家标准的对比结果，含当前值、国标限值、达标进度条和等级评定
  • 能效等级评定：按车间/产线进行 1/2/3 级能效等级评定，附评定说明
  • 行业标杆对比：柱状图对比"本企业 vs 行业平均 vs 国内先进 vs 国际先进"
  • 差距分析面板：多维度差距展示（与国内/国际先进水平的百分比差距），含 KPI 卡片
  • 节能潜力估算：基于差距分析，估算各环节的节能潜力和节能量
  • 节能目标设定：表单式年度目标设定（强度目标、节能量、下降率、可再生能源占比、对标行业、目标年份）
  • 对标历史记录：历年对标数据的增删改查和对比趋势
  • 组织架构和日期范围筛选（与模块1/2一致的工具栏）

3.5 能效等级评定标准

3.5.1 等级判定（按车间/产线）

等级判定条件颜色标识含义
1级（先进）实际值 ≤ 国标先进值（即所有指标均优于或等于国标准入值，且关键指标达到行业先进）绿色达到行业领先水平，可作为内部标杆
2级（中等）国标准入值 ＜ 实际值 ≤ 国标限值（即满足国标要求但未达到先进水平）橙色达到国标准入标准，需持续优化
3级（落后）实际值 ＞ 国标限值（即未达到国标最低要求）红色未达标，需重点整改

3.5.2 综合等级评定规则

对每个车间/产线，按"短板原则"综合评定：

  1. 取该车间所有对标指标中等级最低（数值最大）的一项作为综合等级
  2. 例如：车间A在5项指标中4项为1级、1项为3级 → 综合等级评定为3级
  3. 等级评定结果用于：能效排名、目标考核和节能改造优先级排序

3.7 指标计算公式详解

3.7.1 能效偏差率 — 国标对标面板·差距列

项目内容
公式Δi = (V实际,i − V基准,i) ÷ V基准,i × 100%
符号Δi：第 i 项指标的偏差率(%)；V实际,i：该指标的实际值；V基准,i：该指标的国标限值或行业先进值
判定规则对于"越低越好"型指标（能耗类）：Δ ≤ 0 → 达标（绿色）；Δ ＞ 0 → 超标（红色）
对于"越高越好"型指标（效率类）：Δ ≥ 0 → 达标（绿色）；Δ ＜ 0 → 不达标（红色）
示例单位产品能耗：实际 156.8 kgce/t，限值 180.0 → Δ = (156.8-180.0)÷180.0 = -12.9% → 达标
锅炉热效率：实际 92.3%，限值 88.0% → Δ = (92.3-88.0)÷88.0 = +4.9% → 达标

3.7.2 对标达成率 — 进度条百分比

项目内容
公式（越低越好型）Ri = V基准,i ÷ V实际,i × 100%（R ≤ 100% 时达标，R 越高越好）
公式（越高越好型）Ri = V实际,i ÷ V基准,i × 100%（R ≥ 100% 时达标）
示例（越低越好）单位产值能耗：实际 0.38，国标 0.45 → R = 0.45÷0.38 = 118%（超额达标，显示为 green）
示例（越高越好）余热回收率：实际 62.5%，国标 70.0% → R = 62.5÷70.0 = 89%（未达标，显示为 orange）

3.7.3 综合达标率 — KPI 卡片

项目内容
公式R综合 = N达标 ÷ N总计 × 100%
符号N达标：达到国标或行业限值的指标数量；N总计：参与对标的指标总数（默认 6）
示例6 项指标中 5 项达标 → R综合 = 5÷6 = 83.3%

3.7.4 与行业差距（加权综合）— KPI 卡片

项目内容
公式G行业 = Σi=1n (wi × |Δi|) ÷ Σwi
符号G行业：与行业先进水平的加权平均差距(%)；wi：第 i 项指标的权重（默认等权 1/6）；|Δi|：第 i 项指标与行业先进值的绝对偏差率
示例6 项指标与国内先进的偏差率分别为 4.5%, 6.8%, …, 8.2% → 加权平均 = 12.5%

3.7.5 节能潜力估算 — KPI 卡片

项目内容
公式S潜力 = Σi=1n [Ei × max(0, (V实际,i − V先进,i) ÷ V实际,i)]
符号S潜力：估算的年度节能潜力(tce)；Ei：第 i 项指标对应的年度能耗量(tce)；V实际,i：实际值；V先进,i：行业先进值
示例单位产品能耗达标至行业先进，可节能量 = 当前能耗 × (156.8-135.6)÷156.8 = 1,906.78 × 0.135 = 257 tce
叠加其他指标，合计潜力约 386.5 tce/年

3.7.6 公式汇总速查表

序号公式名称公式单位所在位置

3.8 界面设计要求

  • 顶部工具栏：组织架构级联选择器 + 日期范围 + 刷新按钮（与模块1/2一致）
  • 国标对标卡片：3列×2行网格，白色卡片样式，每张含指标名+等级徽章+当前值+限值+进度条
  • 能效等级列表：按车间纵向排列，左侧勋章图标、中间名称说明、右侧等级徽章
  • 图表区：左右并排两图（行业对比柱状图 + 差距分析水平柱状图）
  • KPI 卡片：4列网格（差距KPI × 4）
  • 目标设定表单：2列×3行 + 操作按钮行
  • 数字字体：D-DIN 用于所有数值显示
  • 等级颜色：1级绿色(#52C41A) / 2级橙色(#FAAD14) / 3级红色(#FF4D4F)
  • 差距颜色：优于基准绿色(#gap-good) / 差于基准红色(#gap-bad)
  • 全部使用 Element UI 组件 + ECharts 图表
